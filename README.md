# Yassin Asermouh

Researcher and freelancer. I study data science and work on artificial intelligence, along with the interfaces built around it.

**Selected work**

- [BioRL](https://github.com/Thedarkiin/Neurobiological_sac). A brain-inspired replay buffer for reinforcement learning. Novelty, strengthening and forgetting decide which experiences an agent keeps, and the buffer plugs into Soft Actor-Critic without changing anything else.
- [Physics-informed wind forecasting](https://github.com/Thedarkiin/physics-informed-wind-transformer). A Transformer for 24-hour wind power forecasting that builds aerodynamic laws into its features and adds a loss designed to anticipate sudden power ramps.
- [AI Trader](https://github.com/Thedarkiin/Trader). A multi-agent paper-trading desk. LLM specialists debate each trade, while plain Python owns every calculation and every decision.
- [Telecom churn prediction](https://github.com/Thedarkiin/Telecom-churn-prediction). A retention system in a Flask app that predicts customer churn and points to its causal features.

**Current interests**

- Causal inference
- Data engineering (Apache tools, HDFS, Snowflake)
- Systems design
- Neuroplasticity
- Medical AI, specifically 3D segmentation (U-Net, SegResNet)
- Imitating human learning in RL-free models

**Tools**

Python, PyTorch, TensorFlow, Pandas, Snowflake, React, TypeScript, Tailwind, Figma.
